# Test data

- `theoph.csv`: R's `datasets::Theoph` (theophylline after a single oral dose in 12
  subjects; Boeckmann, Sheiner and Beal, *NONMEM Users Guide*, 1994), exported with
  R 4.5.2. `Dose` is in mg/kg, so the dose amount is `Dose * Wt` mg; `conc` is in mg/L
  and `Time` in hours.
- `nlmixr2_posthoc_theoph.csv`: nlmixr2 posthoc (empirical Bayes) estimates of
  `eta.ka`, `eta.cl`, `eta.v` per subject on `nlmixr2data::theo_sd` (identical to
  `theoph.csv`) at the fixed parameters of `test/common.jl`, generated by
  `test/oracles/nlmixr2_posthoc_theoph.R` with nlmixr2 7.0.1, nlmixr2est 7.1.0,
  rxode2 5.1.7.1 and R 4.5.2. A test-only oracle: the suite compares against this
  file and needs no R.
- `nlmixr2_posthoc_theoph_predictions.csv`: from the same script, nlmixr2's
  individual predictions at its EBEs (`IPRED`) and typical-value predictions (`PRED`)
  per observation.
- `saemix_saem_theoph.csv`: saemix 3.5 estimates on `theoph.csv`, generated by
  `test/oracles/saemix_theoph.R` with R 4.5.2. The script uses the same oral
  one-compartment model, CL weight exponent, diagonal Ω, and additive residual
  error as `test/common.jl`. It is a test-only SAEM oracle; the suite needs no R.
