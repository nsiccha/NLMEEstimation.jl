NLMEEstimation.NLMEEstimation Module
julia
NLMEEstimation

Model-agnostic estimators for nonlinear mixed-effects (NLME) models.

A model is any Julia value for which the protocol functions are implemented (see nsubjects, nlme_layout, and per evaluation_style either conditional_loglikelihood or conditional_loglikelihoods). The package owns the random-effect prior η_i ~ N(0, Ω) and its parameterization (see NLMELayout); the model owns everything else.

Derivatives come from automatic differentiation: a model either implements the derivative methods itself or declares an AD backend through ad_backend. The package promises and tests reverse-mode AD with Enzyme. Second order is optional and only ever per-subject blocks (provides_eta_hessian).

Estimators:

  • empirical_bayes (alias posthoc): per-subject posterior modes (EBEs), by Newton on Hessian blocks or by gradient-only BFGS, at fixed population parameters.

  • focei: population estimation using first-order conditional curvature and a derivative-free outer optimizer.

  • saem: population estimation by MCMC stochastic approximation.

covariance_step gives standard errors of a fit's population coordinates, and marginal_loglikelihood its likelihood, OFV, AIC and BIC (for SAEM, by importance sampling or adaptive Gauss–Hermite quadrature). residual_diagnostics gives PRED, IPRED, IWRES, CWRES and NPDE.

Each of these functions takes progress = nothing: a Treebars node under which it builds its own labelled progress node, or a backend symbol such as :term for a new root. With nothing no node is created. Treebars.request_interrupt! on that node stops saem and focei early with their estimate so far; the other functions raise Treebars.ProgressInterrupted.

NLMEEstimation.AdaptiveGaussHermite Type
julia
AdaptiveGaussHermite(; nodes = 5, max_points = 100_000)

Adaptive Gauss–Hermite quadrature of each subject's marginal log-likelihood: nodes points per random-effect dimension, as a tensor product, centred at the subject's conditional mode and scaled by its inverse curvature (computed as for ImportanceSampling). nodes = 1 is the Laplace approximation. A subject with d random effects costs nodes^d batched evaluation points; a subject needing more than max_points is refused.

NLMEEstimation.BatchedEvaluation Type
julia
BatchedEvaluation()

The model evaluates a batch of subjects per call: it implements conditional_loglikelihoods. Per-subject entry points evaluate a batch of one; derivatives of a batch come from AD of the batch's summed log-density, which yields every subject's η-gradient at once because subjects are conditionally independent.

NLMEEstimation.CovarianceResult Type
julia
CovarianceResult

Result of covariance_step. point is the full concatenated population vector [θ; σ; ω] at which the step was taken, in the model's unconstrained coordinates and the package's log-Cholesky ω. coordinates is the same point in the coordinates the estimators fit: [θ; σ; free Ω coordinates]. It equals point unless the model declares fixed_omega; then a fully fixed family has no coordinates, and a partially fixed family contributes its estimated log standard deviations (named log sd(…)) and, when its correlation is estimated, its correlation coordinates m_jl = L_jl / L_jj of the Cholesky factor L (named m(…)). Every other vector and matrix field is indexed by the estimated coordinates free (positions in coordinates), named in names:

  • covariance, standard_errors: the estimated sampling covariance of those coordinates and the square roots of its diagonal, for method :rs (R⁻¹ S R⁻¹), :r (R⁻¹) or :s (S⁻¹).

  • R: minus the Hessian of the fitted objective, the summed marginal log-likelihood plus any population_logprior (objective is :ML or :MAP); nothing for method = :s, which does not compute it.

  • S: Σᵢ gᵢ gᵢᵀ over the subjects' marginal log-likelihood gradients gᵢ, the columns of subject_gradients. A population prior is not a subject term and enters R only.

  • gradient: the gradient of the fitted objective, close to zero at a converged estimate.

  • step: the central-difference step per coordinate; evaluations counts the marginal-approximation evaluations.

Use delta_method for natural-unit quantities.

CovarianceStepError

Thrown by covariance_step when the requested covariance does not exist: R is not positive definite (methods :rs and :r) or S is singular (method :s, for example with fewer subjects than estimated coordinates). The fields R, S, gradient and names hold what was computed, for diagnosis.

NLMEEstimation.DualAveragingMALA Type
julia
DualAveragingMALA(; metric=:prior, initial_stepsize=0.1,
                    target_acceptance_rate=0.574,
                    gamma=0.05, t0=10.0,
                    min_stepsize=1e-5, max_stepsize=10.0,
                    curvature_floor=1e-4)

MALA with one independent dual-averaging step size per subject. metric=:prior uses the current Ω as proposal covariance. metric=:hessian obtains a fixed per-subject covariance from the initial regularized local posterior Hessian, falling back to Ω if the model has no Hessian. That fallback stays the starting Ω: when a variance component then shrinks, the step size shrinks with its posterior, and the chains can stop moving. Gradients are evaluated in subject batches. The source gradient is reused after each accept or reject until a population M-step changes the target. Adaptation continues at every transition, including during population updates. This changing-target, continuously adapted mode is experimental; its transition is Metropolis corrected at each fixed population state, but a full SAEM convergence guarantee is not implied.

EBEOptions(; maxiter = 200, decrement_tol = 1e-14, gtol = 1e-8, max_backtracks = 30)

Settings of empirical_bayes.

  • maxiter: maximum number of iterations (accepted steps) per subject.

NLMEEstimation.EBEResult Type
julia
EBEResult

Result of empirical_bayes. Column/entry k of every field belongs to subject subjects[k].

  • modes: neta × length(subjects) matrix of empirical Bayes estimates η̂_i.

  • hessians: the neta × neta Hessian in η of the complete-data log-density log p(y_i, η_i | θ, σ, Ω) at η̂_i per subject, or nothing when the model provides no second order (see ebe_covariances).

  • conditional_loglikelihood, complete_data_loglikelihood: the two log-densities at η̂_i.

  • gradient_norm: the standardized complete-data gradient ‖Lᵀg‖∞ at η̂_i.

  • method: the EBEMethod used.

NLMEEstimation.FOCEApproximation Type
julia
FOCEApproximation(; interaction = true, ebe_method = nothing,
                    ebe_options = EBEOptions(gtol = 1e-10))

The FOCE(I) approximation of each subject's marginal log-likelihood, the per-subject terms of focei_evaluate, as used by covariance_step. interaction = false gives FOCE without interaction. ebe_method = nothing selects default_ebe_method: Newton when the model provides η Hessian blocks, otherwise BFGS. NLMEEstimation.FixedOmega Type
julia
FixedOmega(Ω::AbstractMatrix)
FixedOmega(; sd = nothing, correlation = nothing)

A known value for all or part of one random-effect covariance family, declared through fixed_omega. FixedOmega(Ω) holds the whole family at the covariance matrix Ω, like nlmixr2's fix() on an ω block or NONMEM's OMEGA … FIX.

The keyword form fixes parts of a family in standard-deviation and correlation terms, Ω = D R D with D = Diagonal(sd):

  • sd is nothing (every margin estimated) or a vector with one entry per margin: a positive standard deviation for a fixed margin, and nothing or missing for an estimated one;

  • correlation is nothing (estimated) or the known correlation matrix R, symmetric positive definite with unit diagonal.

The estimators fit the remaining parts with the fixed parts held at their values. A family of size one has only its standard deviation.

NLMEEstimation.ImportanceSampling Type
julia
ImportanceSampling(; draws = 2000, df = 4, scale = 1.0)

Importance-sampling estimate of each subject's marginal log-likelihood log ∫ p(y_i | θ, σ, η) N(η; 0, Ω) dη. The proposal for subject i is a multivariate Student t with df degrees of freedom (a positive integer, or Inf for a Gaussian), centred at the subject's conditional mode, with scale matrix scale² times the inverse curvature of the complete-data log-density there. The curvature comes from the η Hessian blocks when the model provides them, and otherwise from central differences of batched η gradients. Each draw costs one batched conditional evaluation over all subjects. The estimate reports its Monte Carlo standard error and per-subject effective sample sizes.

source
NLMEEstimation.LouisInformation Type
julia
LouisInformation(; draws = 1000, burnin = 200, kernel = WarmupHMCNUTS())

covariance_step's information matrices by Louis's missing-information identity (Louis 1982), from posterior draws of the random effects at the point: SAEM's stochastic-approximation Fisher information (Kuhn & Lavielle 2005; Monolix's default, nlmixr2's SAEM "sa"). For subject i, with ψ the estimated coordinates and draws η_i ~ p(η_i | y_i, ψ),

julia
-∂²ψ log p(y_i | ψ) = E[-∂²ψ log p(y_i, η_i | ψ)] - Var[∂ψ log p(y_i, η_i | ψ)]
 ∂ψ log p(y_i | ψ)  = E[∂ψ log p(y_i, η_i | ψ)]

so R (the summed first line) and S (the outer products of the second) need neither a marginal likelihood nor the curvature in η. The complete-data log density is taken in the mu-referenced coordinates φ = η + Xθ_μ, in which the model depends on the mu-referenced θ only through the Gaussian prior. The derivatives in those θ and in ω are closed form. Those in the other θ and in σ come from conditional_loglikelihood_and_population_gradient (one call per subject and draw), and their curvature from central differences of the summed population gradient (two batched calls per coordinate and draw, with covariance_step's step).

kernel, a WarmupHMCNUTS, draws each subject's η: a warmup from the starting η (a fit's chain states or modes), burnin discarded transitions, then draws kept ones. R and S carry Monte Carlo error that falls as 1/√draws. It applies to any likelihood and to both layouts, and keeps no n × n matrix per subject; for a subject with thousands of nested random effects, declare eta_hessian_sparsity so NUTS's warmup metric is sparse too. It is not a marginal likelihood: marginal_loglikelihood refuses it.

NLMEEstimation.MarginalLikelihoodResult Type
julia
MarginalLikelihoodResult

Result of marginal_loglikelihood. point is [θ; σ; ω]. loglikelihood is the marginal log-likelihood with every constant kept, and subject_loglikelihoods[k] is subject subjects[k]'s term. standard_error and subject_standard_errors are Monte Carlo standard errors. They are zero for the deterministic approximations, which report no approximation error. effective_sample_size holds the per-subject importance sampling effective sample sizes, or nothing.

logposterior adds a model population_logprior once (objective :MAP). ofv is -2 logposterior, as in FOCEResult, and equals -2 loglikelihood under :ML. nlmixr2's OBJF omits the Gaussian constant: it is ofv - nobs * log(2π). aic = -2 loglikelihood + 2 nparameters and bic = -2 loglikelihood + nparameters * log(nobs), where nobs counts the observations of the listed subjects. nobs, and so bic, is missing for a model that declares no observation_model unless it is passed explicitly. evaluations counts batched conditional evaluations (missing for FOCEApproximation).

NLMEEstimation.MuReferencing Type
julia
MuReferencing(theta_indices, design)

Mu-referencing declaration (see mu_referencing).

  • theta_indices: the θ coordinates that are mu-referenced.

  • design: one neta × length(theta_indices) matrix X_i per subject.

Contract: for every subject i, conditional_loglikelihood depends on θ[theta_indices] and η only through the individual linear predictor ϕ_i = X_i * θ[theta_indices] + η. Equivalently, it is unchanged under θ[theta_indices] .+= δ, η .-= X_i * δ. The model applies its own inverse link to ϕ_i. A zero row of X_i marks an η component without a mu-referenced typical value.

NLMEEstimation.NLMELayout Type
julia
NLMELayout(; ntheta, nsigma, eta_blocks)

Parameter layout of an NLME model, returned by nlme_layout.

  • ntheta: length of θ, the population (fixed-effect) coordinates.

  • nsigma: length of σ, the other scalar coordinates the conditional density depends on (residual-error parameters, for example).

  • eta_blocks: sizes of the mutually independent blocks of the per-subject random-effect vector η_i, in η order. sum(eta_blocks)is the η dimension (neta). A diagonal Ω isones(Int, neta); one dense Ω is[neta].

θ and σ are in the model's own unconstrained coordinates: every real vector of the right length is a valid input to conditional_loglikelihood.

Ω is owned by this package. Its unconstrained parameter vector ω is the concatenation, block by block, of the log-Cholesky coordinates of each block Ω_b = L_b L_bᵀ: the entries of the lower triangle of L_b in row-major order (L[1,1], L[2,1], L[2,2], L[3,1], …), with each diagonal entry stored as its logarithm. For a block of size one, the coordinate is log(sd). nomega gives the length of ω.

NLMEEstimation.NewtonEBE Type
julia
NewtonEBE()

Trust-region Newton on the complete-data Hessian blocks. Each step maximizes the local quadratic model of the complete-data log-density over a ball in the standardized coordinates L⁻¹η, with Ω = LLᵀ. Inside the ball that is the full Newton step when -H is positive definite; where -H is indefinite (a saddle or a non-concave region) the step follows the directions in which the density curves upward, out to the radius. The radius shrinks after a rejected step or a poor prediction and grows after a good step that reached it. A subject converges once gᵀ(-H)⁻¹g / 2 ≤ decrement_tol; the Newton step from there is taken as a final polishing step, so the returned mode is stationary to roundoff.

The Hessian blocks are the model's own (provides_eta_hessian), or sparse matrices computed from its batched gradients when it declares eta_hessian_sparsity. On a sparse block the trust-region step is found by sparse Cholesky factorizations of -H + νΩ⁻¹ (Moré & Sorensen 1983) instead of an eigendecomposition, so a subject with thousands of nested effects costs time and memory proportional to the Hessian's nonzeros.

NLMEEstimation.QuasiNewtonEBE Type
julia
QuasiNewtonEBE(; memory = 20)

Limited-memory BFGS per subject on η gradients, with backtracking (halving) to the Armijo condition. The inverse-Hessian approximation applies the last memory curvature pairs to the prior covariance Ω, rescaled at every update to the curvature last observed. A subject with n random effects therefore stores O(memory · n) numbers, and Ω is applied block by block for a RaggedNLMELayout. A subject converges once its standardized gradient ‖Lᵀg‖∞ ≤ gtol, with Ω = LLᵀ (the gradient with respect to the standardized random effects L⁻¹η), and the complete-data density is concave there.

BFGS keeps a positive-definite curvature model, so on its own it cannot follow a direction in which the density curves upward: a saddle point passes the gradient test, and next to one the steps along that direction stay tiny. The solver therefore checks the complete-data Hessian block where BFGS meets upward curvature (a curvature pair with sᵀy ≤ 0, which BFGS skips) and, once no subject is still iterating, at every subject that passed the gradient test. The block is sparse when the model declares eta_hessian_sparsity (two batched gradient calls per color of its pattern), else the model's own when it provides_eta_hessian (the one the result reports, so the check adds no model calls), and otherwise forward differences of batched gradients (neta batched gradient calls per check, not reported in the result). Where -H is not positive definite, the next step is NewtonEBE's trust-region step with a radius of one prior standard deviation, halved until the density increases, and BFGS restarts from Ω.

NLMEEstimation.ResidualDiagnostics Type
julia
ResidualDiagnostics

Per-observation residual diagnostics from residual_diagnostics. Every field below except subjects, modes and replicates holds one vector per subject in subjects, in observation order:

  • observations: y.

  • pred: population predictions, the observation means at η = 0.

  • ipred: individual predictions, the means at the subject's EBE η̂ (modes).

  • iwres: (y - ipred) / sqrt(v(η̂)), with v the observation variance.

  • cpred: the population mean of the first-order linearization around η̂, μ(η̂) - J η̂ with J = ∂μ/∂η at η̂.

  • cwres: conditional weighted residuals: U (y - cpred). Here U is the upper Cholesky factor of the inverse of the linearized covariance C = J Ω Jᵀ + diag(v(η̂)), so UᵀU = C⁻¹ and cwres is decorrelated within the subject.

  • cwres_per_observation: (y - cpred) ./ sqrt.(diag(C)), each observation standardized without decorrelation; this is what nlmixr2 reports as CWRES.

  • epred, npd, npde: simulation-based diagnostics over replicates datasets simulated at the population parameters. epred is the simulated mean, and npd the normal quantile of the prediction discrepancy, the fraction of simulated values below y. npde is the same after decorrelation by the Cholesky factor of the inverse simulated covariance, as for cwres. pde is the decorrelated discrepancy before the quantile. A discrepancy of 0 or 1 is replaced by 1/(2K) or 1 - 1/(2K) for K replicates. These fields are nothing when replicates = 0.

Under a correct model, cwres and npde are approximately independent standard normal values.

NLMEEstimation.SAEMOptions Type
julia
SAEMOptions(; iterations=300, burnin=150, mcmc_burnin=20,
             mh_rounds=1, rw_scale=0.5, adapt_iterations=150,
             step_exponent=0.8, numeric_maxiter=12, mstep_interval=1,
             numeric_mstep=:auto,
             omega_floor=1e-8, omega_annealing=0.95,
             minibatch_size=nothing)

Settings for saem. The first burnin stochastic-approximation iterations use step size one; subsequent sizes are (k-burnin)^(-step_exponent). mcmc_burnin runs kernel sweeps at the starting population parameters without updating them. With StandardSAEMMH, each round makes one prior-independence and one joint random-walk proposal for every subject, then one random-walk proposal per η coordinate, each evaluated in one batch. The joint random-walk scale adapts toward 0.3 acceptance and each coordinate's scale toward 0.4 for the first adapt_iterations sweeps; then they are frozen. With WarmupHMCNUTS, each round makes one fixed-kernel NUTS transition per subject. omega_floor is a covariance eigenvalue floor in the M-step. With few subjects for the mu-referenced coefficients, the covariance that maximizes an M-step's Gaussian term can be singular; its closed-form update moves towards the floor by at most 100 coordinate updates per M-step, so Ω may approach it over several iterations. omega_annealing=0.95 anneals Ω while γ = 1, as Monolix and saemix do: an M-step may shrink no covariance family by more than that factor in any direction (its new Ω is at least omega_annealing times the previous one in the matrix order). Each such M-step sets Ω from one posterior draw per subject, so Ω wanders, and where it wanders towards a singular correlation, kernels whose proposals follow Ω cannot leave it. omega_annealing=0 turns it off and reproduces fits from before it was introduced. numeric_mstep=:auto uses an online update for remaining σ coordinates when all θ coordinates have a closed-form MuReferencing update; otherwise it uses the historical running-mixture objective. Either numerical update also moves the mu-referenced θ, holding each sampled η fixed. :online explicitly applies the online update to every remaining θ and σ coordinate: it optimizes the current complete-data conditional likelihood, then moves toward that optimizer by the SA step size, retaining one sampled latent-effect matrix. Its use for a structural θ without a declared sufficient statistic is an approximation. :mixture optimizes the exact running conditional-density mixture and retains every sampled matrix. The default mstep_interval=1 updates population parameters every SA iteration; a larger interval is an approximate, lower-frequency variant in :online mode. With DualAveragingMALA, each round makes one batched MALA proposal and updates a separate subject step size throughout the run. Set mcmc_burnin=0 to omit a separate initial MCMC phase; burnin still controls the SA step sizes.

minibatch_size=nothing moves every subject's chain at every iteration. An integer b runs minibatch SAEM (Kuhn, Matias & Rebafka 2020): each SA iteration draws b of the n fitted subjects uniformly at random without replacement, and only their chains move. The mcmc_burnin sweeps still move every chain (and the first iteration does when mcmc_burnin = 0), so that each starts from its conditional posterior at the starting estimate; from chains left at their start, the first γ = 1 M-steps would shrink Ω, and with it every proposal scaled by Ω. The other subjects keep their last sampled latent effects, which stay in the stochastic-approximation statistics, so the Gaussian block uses every subject without evaluating the model. The numerical update evaluates the batch alone: each M-step takes one Robbins–Monro step min(γ, 4b/n) M ĝ along the batch's score ĝ, its conditional log density scaled to all n subjects. The cap limits a step to four times the batch's share of a Newton step, so one pass over the subjects nearly solves the update, as a full-batch search does, without the batch's whole sampling error. M is the inverse curvature of the full objective, estimated from every subject's chain at M-steps 1, 2, 4, 8, …. The step's mean is the full score, so the estimates converge to the same fixed point as full-batch SAEM, where a search to each batch's optimum would converge to a point biased by order 1/b. numeric_mstep must be :auto; the result reports :minibatch, and numeric_maxiter is unused. Each chain moves in only a fraction b / n of the iterations. b equal to n is the full-batch algorithm.

NLMEEstimation.SAEMResult Type
julia
SAEMResult

Population estimate from saem. eta holds the final subject-chain states, one column per entry of subjects. acceptance gives prior and joint random-walk and per-coordinate random-walk acceptance fractions (prior, random_walk, coordinates); rw_scale is the final joint proposal scale. These MH-only fields are missing for other kernels. kernel identifies the method and nuts_divergences counts its fixed-kernel transitions that diverged. For MALA, mala_stepsizes and mala_acceptance hold per-subject final values; mala_adaptation_steps counts updates per subject, the fewest any subject received under minibatch_size. The acceptance fractions are over every subject's proposals, so under minibatch_size over the batches'. numeric_mstep records the resolved numerical M-step mode (:online or :mixture, :minibatch under minibatch_size). objective is :ML without a model population prior and :MAP otherwise. The result is a population point estimate, not a draw from a population posterior. iterations counts the completed SA iterations; interrupted is true when a Treebars interrupt request (see progress in saem) stopped the run before SAEMOptions.iterations, so the estimate is that of the last completed iteration. The acceptance and MALA fields are NaN when no kernel sweep ran.

NLMEEstimation.StandardSAEMMH Type
julia
StandardSAEMMH()

The standard SAEM per-subject kernel: per subject and MH round, one prior-independence proposal, one covariance-scaled random-walk Metropolis proposal, and one random-walk proposal per η coordinate, each coordinate with its own adapted scale (saemix's componentwise kernel). NLMEEstimation.check_protocol Method
julia
check_protocol(model, θ, σ, ω; subjects = 1:nsubjects(model), η = nothing,
               reference_backend = nothing, reference_hessian_backend = reference_backend,
               population_gradient = false, rtol = 1e-8) -> true

Check that model implements the protocol consistently at the given parameters, and throw a ProtocolViolation naming the first violation otherwise.

Checked for the batch subjects at random effects η (zeros by default; a neta × length(subjects) matrix, one vector for all subjects, or one vector per subject):

  • the layout matches the lengths of θ, σ and ω, and evaluation_style is an EvaluationStyle;

  • the batched log-densities are finite reals and equal the per-subject ones;

  • the batched gradients equal the per-subject gradients, and the values returned alongside derivatives equal the plain values;

  • subjects are separable: changing one subject's η leaves every other subject's log-density unchanged;

  • when provides_eta_hessian: the Hessian blocks are square, symmetric and equal the per-subject Hessians;

  • a declared eta_hessian_sparsity pattern exists for every checked subject, has its size, and covers every nonzero entry of the η Hessian: the sparse Hessian recovered from it, times a random direction, equals the Hessian-vector product along that direction (central differences of the batched gradients, within max(rtol, 1e-5));

  • a declared mu_referencing trait has one design per subject of the right size, and the density is invariant under the mu-referencing shift;

  • a declared observation_model reproduces the conditional log-density.

  • a declared Gaussian model's batched moments and first-order η Jacobians have the promised per-subject shape and agree with its plain moments;

  • a declared fixed_omega is valid for the layout, and ω holds its fixed values.

With reference_backend (an AD backend), the model's η gradients are also compared against that backend, and its Hessian blocks (when provided) against reference_hessian_backend (for Enzyme, a forward-over-reverse DifferentiationInterface.SecondOrder). With population_gradient = true, the optional θ/σ gradient is checked as well (against reference_backend when given).

NLMEEstimation.covariance_step Method
julia
covariance_step(model, fit::FOCEResult; method = :rs, step = 1e-3,
                approximation = FOCEApproximation(interaction = fit.options.interaction))
covariance_step(model, fit::Union{SAEMResult, RaggedSAEMResult}; method = :rs,
                step = 1e-3, approximation = <see below>, rng = Random.default_rng())
covariance_step(model, θ, σ, ω; subjects = 1:nsubjects(model), free = nothing,
                η0 = nothing, method = :rs, step = 1e-3,
                approximation = FOCEApproximation(), rng = Random.default_rng(),
                progress = nothing)
    -> CovarianceResult

The covariance step: the sampling covariance and standard errors of the estimated population coordinates (θ, σ, ω), in the unconstrained coordinates in which they are fitted.

R is minus the Hessian of the fitted objective and S the sum over subjects of the outer products of their marginal log-likelihood gradients. method = :rs (the default) returns the sandwich R⁻¹ S R⁻¹, which remains consistent when the model's random-effect or residual distribution is misspecified; :r returns the inverse observed information R⁻¹, and :s the inverse cross-product S⁻¹. With a population_logprior, R includes the prior and R⁻¹ is the Laplace approximation of the population posterior covariance at the MAP point.

Both matrices are central finite differences of the per-subject marginal log-likelihoods of approximation, which needs objective values only: no population derivatives of the model. Each coordinate j moves by step * max(1, |x_j|). :s takes 2p + 1 evaluations for p estimated coordinates; :r and :rs take 2p² + 1. Every evaluation warm-starts the subject modes from the same solution at the estimate. With LouisInformation both matrices come instead from posterior draws of the random effects at the point (Louis's identity), and step only differences the population gradient for the curvature in θ and σ.

For a FOCE(I) fit, the defaults reuse its subjects, its fitted coordinates (fit.free) and its interaction setting, so the step differentiates the fitted objective. For an SAEM fit, all (θ, σ, ω) are estimated. A model with GaussianObservations and an NLMELayout defaults to the FOCE(I) linearization at the SAEM estimate. A model with a RaggedNLMELayout defaults to the Laplace approximation, AdaptiveGaussHermite(nodes = 1), when it reports η Hessians (its own blocks, or a declared eta_hessian_sparsity: the rule default_ebe_method uses for Newton), and to LouisInformation otherwise. Any other model defaults to ImportanceSampling. Its draws, from rng, are held fixed across the difference points, so the estimated marginal is a smooth function of the coordinates, and perturbations of ω and of mu-referenced θ reuse the conditional values and cost no model evaluations. AdaptiveGaussHermite is the deterministic alternative. It adapts at every difference point, finding the subject modes and curvature there again (warm-started from the estimate's, gtol = 1e-10), so nodes = 1 gives the Laplace covariance, the one subjects with many random effects need. free selects positions in the estimated coordinates [θ; σ; free Ω coordinates], which are the concatenated (θ, σ, ω) unless the model declares fixed_omega (see CovarianceResult). Fixed covariance parts carry no uncertainty and are never differentiated; ω must hold their values. Throws CovarianceStepError when the requested matrix is not positive definite.

progress (a Treebars node or backend symbol) gets a Covariance step node: the subject modes at the point, then a Marginal likelihoods counter over the 2p² + 1 (or 2p + 1) evaluations. An interrupt raises Treebars.ProgressInterrupted.

NLMEEstimation.empirical_bayes Method
julia
empirical_bayes(model, θ, σ, ω; subjects = 1:nsubjects(model), η0 = nothing,
                method = default_ebe_method(model), options = EBEOptions(),
                require_convergence = true, progress = nothing) -> EBEResult

Empirical Bayes estimates (posthoc): for fixed population parameters θ, σ and Ω parameters ω, the per-subject mode

julia
η̂_i = argmax_η  log p(y_i | θ, σ, η) + log N(η | 0, Ω).

All subjects are solved in lockstep: each iteration makes one batched gradient call (conditional_loglikelihoods_and_gradients) for every subject still iterating, plus batched value calls for its trial steps, so a joint-program model pays O(N) per iteration rather than O(N) per subject. Models are never called concurrently.

η0 is the starting point: nothing (zeros), a neta × length(subjects) matrix, one vector per subject, or an earlier EBEResult covering these subjects (warm start). method is NewtonEBE or QuasiNewtonEBE.

Throws an EBEConvergenceError if some subject's mode is not found, unless require_convergence = false, in which case the result records the failure in converged. A non-finite complete-data log-density at the starting point is always an error. A trial point at which the model returns -Inf or throws a DomainError, OverflowError or PosDefException (a point outside its domain) is rejected, and a shorter step is tried.

Evaluating the complete-data log-density f can round off by many ulps of f when f sums terms much larger than itself, such as observations far from zero with a small residual SD. Near a mode, a full step whose predicted increase is below √eps · max(1, |f|) is therefore accepted unless f decreases by more than that. The convergence tests use gradients and Hessian blocks, which stay accurate there.

progress is a Treebars node (or a backend symbol such as :term) under which an Empirical Bayes (Newton) or (BFGS) node reports the solver's iteration and how many subjects have converged. Treebars.request_interrupt! on it raises Treebars.ProgressInterrupted at the next iteration.

NLMEEstimation.eta_hessian_sparsity Method
julia
eta_hessian_sparsity(model, i) -> Union{Nothing, AbstractMatrix{Bool}}

Optional. Which entries of subject i's conditional η Hessian ∇²η ℓ_i can be nonzero: an n × n Boolean matrix, usually a SparseMatrixCSC{Bool}, with n = neta(nlme_layout(model), i). Entry (j, k) is true when η_j and η_k can enter the same observation's likelihood. The default nothing declares nothing, and the Hessian is treated as dense. A model declares a pattern for every subject or for none.

With a pattern, the estimators compute the subject's η Hessian as a sparse matrix from a few batched gradient evaluations, one pair per color of a star coloring of the pattern (central differences of conditional_loglikelihoods_and_gradients), and factor it sparsely. A subject of nested random effects, whose units interact only through the effects above them, then costs memory and time linear in its number of effects; dense Hessian blocks cost their square. empirical_bayes uses NewtonEBE by default for such a model, its result's hessians are sparse, and marginal_loglikelihood and covariance_step take their curvature from them. The pattern supersedes conditional_loglikelihood_hessian_blocks: a model that declares one is not asked for dense blocks. check_protocol checks a declared pattern against Hessian-vector products along random directions.

The diagonal and symmetry are implied: P .| P' .| I is used.

NLMEEstimation.residual_diagnostics Method
julia
residual_diagnostics(model, fit; replicates = 1000, rng = Random.default_rng(),
                     progress = nothing)
residual_diagnostics(model, θ, σ, ω; subjects = 1:nsubjects(model), η0 = nothing,
                     replicates = 1000, rng = Random.default_rng(),
                     ebe_options = EBEOptions(), progress = nothing) -> ResidualDiagnostics

PRED, IPRED, IWRES, CWRES and NPDE for a model with GaussianObservations, at a fit's estimate or at given population coordinates. Subject modes (EBEs) warm-start from the fit's EBEs or final chain states, or from η0. Both NLMELayout and RaggedNLMELayout are supported.

CWRES follows Hooker, Staatz and Karlsson (2007): the observations of subject i are linearized around its EBE, giving mean μ(η̂) - J η̂ and covariance J Ω Jᵀ + diag(v(η̂)), and the residual is decorrelated by the Cholesky factor of that covariance's inverse. This is the approximation the FOCE(I) objective of focei_evaluate uses, with the residual variance at the EBE.

NPDE follows Brendel, Comets, Laffont, Laveille and Mentré (2006) and Comets, Brendel and Mentré (2008). replicates datasets are simulated at the population parameters (η ~ N(0, Ω), then y ~ N(μ(η), v(η))), each costing one batched observation_moments call. The observed and simulated vectors are decorrelated with the Cholesky factor of the inverse of each subject's simulated covariance. replicates must exceed every subject's number of observations; replicates = 0 skips the simulation.

progress (a Treebars node or backend symbol) gets a Residual diagnostics node with the subject modes and a Simulated replicates counter; an interrupt raises Treebars.ProgressInterrupted.

NLMEEstimation.saem Method
julia
saem(model, θ0, σ0, ω0; rng=Random.default_rng(), subjects=nothing,
     η0=nothing, options=SAEMOptions(), kernel=StandardSAEMMH(),
     progress=nothing) -> SAEMResult

Estimate population parameters using MCMC stochastic approximation. Subject chains persist across iterations. The Gaussian random-effect prior supplies a closed-form covariance M-step; MuReferencing also supplies the generalized-least-squares fixed-effect M-step. Remaining θ and σ coordinates use a first-order AD numerical M-step, which holds each chain's η fixed and so also moves the mu-referenced θ: a σ coordinate that trades off against a random effect then moves together with it. Its quasi-Newton search starts from a difference estimate of the objective's curvature, carried from one M-step to the next. By default, σ coordinates are updated online only when all structural θ coordinates have a MuReferencing sufficient-statistic update. Otherwise the historical running conditional-density objective is used and retains one latent-effect matrix per SA iteration. Set numeric_mstep=:online to force an online update for undeclared structural θ as a model-specific approximation. SAEMResult.numeric_mstep records the selected mode. kernel selects the standard lockstep MH proposals, batched continuously adapted MALA proposals, or per-subject in-memory WarmupHMC NUTS transitions. When population_logprior is supplied, the M-step maximizes the same objectives plus the prior, added once. The mu-referenced θ and Ω move on from their closed-form update to the maximizer with the prior, a search that does not evaluate the model, and the numerical update of the remaining θ and σ includes the prior; so a prior adds no model evaluations to the step. The model supplies a population-prior gradient or an AD backend from which to derive it. Covariance families declared by fixed_omega keep their fixed parts: a fully fixed family is not updated, and a partially fixed family maximizes the expected Gaussian random-effect density over its estimated standard deviations and correlation. ω0 must hold the fixed values (apply_fixed_omega); omega_floor applies to estimated parts only. A model rejects a point outside its domain by returning a log density of -Inf or by throwing a DomainError, OverflowError or PosDefException. The MH and MALA kernels then reject that subject's proposal alone, and the numerical and MAP M-steps halve their line-search step. The point each M-step starts from must evaluate finitely.

SAEMOptions(minibatch_size = b) moves only b randomly drawn subjects' chains per iteration and evaluates only those subjects in the numerical M-step (see SAEMOptions). That M-step screens only the batch's chains, so a chain drawn later can lie outside the model's domain at the population parameters of its next iteration; it is then replaced by a feasible draw from the random-effect prior. The progress message's Σ log p(y|η) is then the batch's sum scaled to all subjects.

progress is a Treebars node (or a backend symbol such as :term) under which a SAEM node shows the run's phases: NUTS warmup (one transient WarmupHMC tree per subject), MCMC burn-in and Stochastic approximation, each counting its iterations. The running message gives the stage (M-step while it runs), the SA step size γ, the chains' summed conditional log-density at the current population estimate (MH and NUTS) and the kernel's acceptance, divergences or mean step size. Treebars.request_interrupt! on that node stops the run at the next iteration boundary: saem returns the estimate of the last completed iteration with interrupted = true and iterations counting the completed SA iterations.

NLMEEstimation.saem_population_gradient_style Method
julia
saem_population_gradient_style(model[, numeric_mode]) -> EvaluationStyle

Optional. Selects how SAEM computes the conditional-likelihood value and population-parameter gradient for its numerical M-step. Defaults to evaluation_style. A model with BatchedEvaluation can return PerSubjectEvaluation here when it implements an efficient conditional_loglikelihood_and_population_gradient for one subject; SAEM sums those subject values and gradients. This choice affects only that M-step gradient. Likelihood, η-gradient, and η-Hessian evaluation continue to use evaluation_style(model).

The optional second argument is Val(:online) or Val(:mixture), the resolved SAEM numerical M-step mode. Override it when one gradient route is efficient for online updates but costly for the retained-draw mixture. By default both modes use the one-argument style, preserving existing model methods.

NLMEEstimation.ReferenceModels.OneCompartmentOral Type
julia
OneCompartmentOral(subjects; backend, error_model = CombinedError(),
                   eta_blocks = [1, 1, 1], reference_weight = 70.0)

One-compartment model with first-order absorption and elimination after a single oral dose, solved analytically. With θ = [log ka, log CL, log V, β_WT]:

julia
log ka_i = θ[1] + η_i[1]
log CL_i = θ[2] + β_WT · log(WT_i / reference_weight) + η_i[2]
log V_i  = θ[3] + η_i[3]
C_i(t)   = dose_i · ka_i / (V_i (ka_i − ke_i)) · (exp(−ke_i t) − exp(−ka_i t)),  ke_i = CL_i / V_i
y_ij     ~ N(C_i(t_ij), residual variance)

Implements the full protocol, including the MuReferencing and GaussianObservations traits. Derivatives come from backend (an ADTypes backend whose package is loaded, for example ADTypes.AutoEnzyme() with Enzyme). eta_blocks sets the Ω block structure ([3] for a dense Ω).
