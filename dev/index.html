NLMEEstimation.jl ​

NLMEEstimation estimates population parameters and subject effects for nonlinear mixed-effects models defined by Julia likelihoods.

These shell commands install the example environment with Julia 1.11 or later:

sh
git clone https://github.com/nsiccha/NLMEEstimation.jl
cd NLMEEstimation.jl && julia --project=docs docs/install.jl

Fit absorption, clearance, volume and residual error in a simulated oral PK study:

julia
using NLMEEstimation, NLMEEstimation.ReferenceModels
using ADTypes, Enzyme, LinearAlgebra, Random
θ = [log(1.2), log(4.0), log(35.0), 0.0]
σ = [log(0.25)]
Ω = Diagonal(fill(0.3^2, 3))
subjects, _ = simulate_one_compartment_oral(MersenneTwister(42), θ, σ, Ω;
    error_model=AdditiveError(), nsubjects=20)
model = OneCompartmentOral(subjects; backend=AutoEnzyme(),
    error_model=AdditiveError())
ω = omega_parameters(nlme_layout(model), Ω)
fit = focei(model, θ, σ, ω; free=[1, 2, 3, 5], options=FOCEOptions(maxeval=800))
println("Converged: ", fit.converged, "; subjects: ", nsubjects(model))
println("ka (1/h), CL (L/h), V (L): ", round.(exp.(fit.theta[1:3]); digits=3))
text
Converged: true; subjects: 20
ka (1/h), CL (L/h), V (L): [1.199, 3.882, 37.12]

This output is from the cached fit and receipt. The fit holds the weight effect and random-effect covariance fixed; free selects the estimated coordinates.

Reading paths ​

Use the oral PK example to inspect the model, its predictions and residuals. For your own likelihood, begin with the model protocol, then choose an estimator. The reference documents the available arguments and result fields.

NLMEEstimation owns the Gaussian random-effect prior and covariance coordinates. Your model supplies the conditional likelihood, parameter layout and derivative backend. A SAEM fit is a population point estimate; its internal chains do not constitute a population posterior sample.
